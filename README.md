# حسابات العمليات

تطبيق أندرويد عربي لتسجيل العمليات والعربون والدفعات والمواعيد والمصاريف العامة. يعمل محليًا دون إنترنت بعد تثبيته.

## البناء على GitHub
1. أنشئ مستودعًا جديدًا على GitHub وارفع جميع ملفات المشروع.
2. افتح تبويب **Actions** وفعّل تشغيل workflows إذا طلب منك ذلك.
3. من **Actions** افتح مهمة **Build Android Debug APK** وشغّلها عبر **Run workflow**، أو ارفع تعديلًا جديدًا.
4. افتح نتيجة التشغيل الناجحة، ثم قسم **Artifacts** ونزّل `hesabat-alamaliyat-debug-apk`.
5. فك ضغط الملف على الكمبيوتر، وانقل ملف APK إلى الهاتف، وافتحه وثبّته. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر.

## ملاحظات
- أول بناء على GitHub يحتاج إنترنت لتنزيل أدوات البناء ومكتبات Capacitor؛ التطبيق نفسه لا يحتاج الإنترنت بعد التثبيت.
- البيانات محفوظة على الجهاز. احفظ نسخة JSON احتياطية دوريًا، ولا تمسح بيانات التطبيق قبل التصدير.
- إشعارات المواعيد تحتاج إذن المستخدم. أندرويد قد يقيّد دقة التنبيهات بحسب إصدار النظام وإعدادات البطارية.
- هذا بناء Debug للتجربة والتثبيت اليدوي، وليس إصدارًا منشورًا على Google Play.

## الخط
الواجهة تضبط Tajawal كخط مفضل مع بدائل عربية مناسبة عند عدم توفره. التطبيق لا يعتمد على تحميل بيانات من الإنترنت.
